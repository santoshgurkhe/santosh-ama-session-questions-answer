## AMA - 29 Aug

- **What is a FULL OUTER JOIN?**  
  A FULL OUTER JOIN returns all matching rows from both tables. It also includes unmatched rows and fills missing values with NULL.

- **What is a dynamically typed language?**  
  In a dynamically typed language, you do not need to declare the variable type. For example, Python decides the type at runtime.

- **What are primary keys and foreign keys?**  
  A primary key uniquely identifies each row in a table. A foreign key connects one table with another table.

- **What happens when you call a constructor in Python?**  
  When you create an object, the constructor __init__ is called automatically. It is used to initialize the object's data.

- **What are indexes in SQL?**  
  Indexes help the database find data faster. They improve query performance, especially for large tables.

- **Which query is used to check which tables are present in a database?**  
  In PostgreSQL, you can use `\dt` to see the tables in the current database.

- **Which commands are used to run SQL files in psql?**  
  You can use `psql -h localhost -d database_name -f file.sql` inside psql.

- **Which commands are used to switch branches and merge branches in Git?**  
  Use `git switch branch_name` to switch branches. Use `git merge branch_name` to merge another branch.

- **Who introduced the SOLID principles?**  
  Robert C. Martin, also known as Uncle Bob, introduced and popularized the SOLID principles.

- **How can you grant all permissions to a user in a database?**  
  Use the `GRANT ALL PRIVILEGES` command. For example: GRANT ALL PRIVILEGES ON DATABASE db_name TO user_name;.

- **What do you understand by a relational database?**  
  A relational database stores data in tables. These tables can be connected to each other using keys.

- **Can you explain the ACID properties?**  
  ACID stands for Atomicity, Consistency, Isolation, and Durability. These properties help keep database transactions reliable and safe.

- **What are triggers in a database?**  
  A trigger is a database action that runs automatically when an event like INSERT, UPDATE, or DELETE happens.
