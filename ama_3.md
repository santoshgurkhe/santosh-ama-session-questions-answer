# AMA - 15 Sep

## 1. What are promises in JavaScript?

A Promise is an object used to handle an asynchronous task. It can be **pending, fulfilled, or rejected**.

## 2. What is the difference between `Object.assign()` and `Object.entries()`?

`Object.assign()` copies properties from one object to another. `Object.entries()` returns an array of key-value pairs from an object.

## 3. What is callback hell?

Callback hell happens when many callbacks are nested inside each other, making the code difficult to read and maintain.

## 4. What do you mean by scope?

Scope defines where a variable can be accessed in the code. For example, a variable inside a function cannot be accessed outside that function.

## 5. What is the functionality of the event loop?

The event loop checks the call stack and queues and moves tasks to the call stack when it is free.

## 6. What are the disadvantages of callbacks?

Too many callbacks can make code difficult to read and maintain. It can also lead to callback hell.

## 7. What is the difference between `git reset` and `git revert`?

`git reset` moves the branch back and can remove commits from the history. `git revert` creates a new commit that undoes the changes of an earlier commit.

## 8. What is the difference between an object and a string?

An object stores data as key-value pairs, while a string stores a sequence of characters.

## 9. What is a constructor function in JavaScript?

A constructor function is used to create multiple objects with the same structure. It is called using the `new` keyword.

## 10. Why do we need promises?

Promises make asynchronous code easier to handle and help avoid deeply nested callbacks.

## 11. What is the purpose of `Math.trunc()`?

`Math.trunc()` removes the decimal part of a number and returns only the integer part. For example, `Math.trunc(5.8)` returns `5`.

## 12. What are the different stages of a promise?

A Promise has three stages: **pending, fulfilled, and rejected**. It starts as pending and then becomes fulfilled or rejected.
